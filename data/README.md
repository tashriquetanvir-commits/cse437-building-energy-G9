# Dataset

## Dataset Name

Building Energy Benchmarking Data, 2015–Present

## Source

City of Seattle Open Data

Dataset page:

https://data.seattle.gov/Built-Environment/Building-Energy-Benchmarking-Data-2015-Present/teqw-tu6e/about_data

## Raw Data

The original dataset used in this project is stored in:

`data/raw/teqw-tu6e.csv`

The raw file is kept unchanged.

The downloaded dataset contains 38,309 rows and 46 columns covering reporting years 2015–2025.

## Processed Data

Processed files are generated by running the notebooks in numerical order.

`02_preprocessing.ipynb` creates:

`data/processed/seattle_energy_cleaned.csv`

`03_feature_engineering.ipynb` creates:

`data/processed/seattle_energy_features.csv`

## Reproducing the Data Pipeline

1. Keep the original CSV inside `data/raw/`.
2. Run `01_data_audit_and_eda.ipynb`.
3. Run `02_preprocessing.ipynb`.
4. Run `03_feature_engineering.ipynb`.

The later modelling and evaluation notebooks use the processed outputs produced by these steps.
